# Zen-G Wear

Zen-G Wear is a MERN stack application providing cloud services, file management, and a comprehensive admin dashboard.

## Features

- **Authentication & Authorization**: Secure JWT-based login with role-based access control (Admin, User).
- **Redux State Management**: Centralized application state using Redux Toolkit.
- **Protected Routes**: Secure frontend routing using React Router DOM.
- **CRUD Operations**: Complete CRUD for files, folders, services, users, and tickets.
- **Image Upload**: Integrated with Cloudinary via Multer for optimized media management.
- **Error Handling**: Standardized error management on both client and server.
- **Responsive UI**: Fully responsive interface using Tailwind CSS and Framer Motion.

## Technologies

- **Frontend**: React, Vite, Redux Toolkit, Tailwind CSS, Axios, React Router.
- **Backend**: Node.js, Express, MongoDB, Mongoose, JWT, Cloudinary, Multer.
